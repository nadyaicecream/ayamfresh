# AYAM FRESH — Landing Page

Landing page jualan ayam potong segar, siap deploy ke GitHub Pages.

## File
- `index.html` — halaman utama
- `style.css` — desain responsive
- `script.js` — tombol pesan WhatsApp
- `products.json` — data produk
- `favicon.svg` — favicon

## Sebelum upload
Ganti nomor WhatsApp di:
1. `index.html` pada link `https://wa.me/6281234567890`
2. `script.js` pada `const phone="6281234567890";`

Gunakan format nomor internasional tanpa tanda `+`.

## Deploy GitHub Pages
1. Buat repository baru di GitHub.
2. Upload semua file.
3. Buka **Settings → Pages**.
4. Pada Source pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Save, lalu tunggu GitHub membuat link website.
